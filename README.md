# Base de datos financiera para Trabajo Práctico Integrador

En este repositorio subiré los archivos SQL del TP dividido en sus diferentes partes como la creación de la base de datos y sus tablas,
los triggers principales(la cantidad mínima de triggers que piden para el TPI (3)),
las vistas principales(la cantidad mínima de vistas que piden para el TPI (3)),
los procedimientos almacenados(los procedimientos almacenados que piden para el TPI (2)),
y, por ultimo, los triggers y vistas extra que complementan a la base de datos.


Su correcta ejecucion de estos archivos sería la siguiente:
1. Ejecutar el archivo creacion.sql
2. Sigue el archivo de Triggers
3. Continúa con los Procedimientos Almacenados
4. La inserción de datos
5. Por último las vistas
